# Supporting Datasets for Network Optimization Hackathon

## 1. Router Logs
Contains hourly network traffic, latency, bandwidth usage, and congestion events over 15 days.

## 2. Network Topology
Details of network nodes and links with capacities.

## 3. Configuration History
Records of configuration changes made to devices over the period.

## 4. Application Usage
Average and peak traffic per application per day.

## 5. User Activity
User login counts and peak usage per day.

## 6. External Factors
External events impacting network performance.
