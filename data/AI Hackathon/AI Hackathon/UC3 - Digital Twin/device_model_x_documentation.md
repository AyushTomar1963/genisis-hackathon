
# Device Model X Documentation

## Overview
Model X is a high-performance network device designed for enterprise environments. It supports:
- Up to 10 Gbps throughput
- Advanced security features
- High availability and redundancy

## Operational Parameters
- CPU Usage: Typical range 10-70%
- Memory Usage: Typical range 10-60%
- Error Rate: Usually below 1%
- Response to high CPU or memory usage: triggers alerts or throttling

## Behavior
- Normal operation logs contain info messages.
- Anomalies include high CPU/memory usage, packet drops, or security alerts.
- Logs are generated hourly with simulated metrics.
